\# Project Overview



\## 1. Project Title



\*\*Library Management System\*\*



\## 2. Introduction



The Library Management System is a desktop-based application developed using Python. It is designed to help manage daily library activities in an organized and efficient way.



The application uses Tkinter for its graphical user interface and SQLite for storing information.



\## 3. Objectives



The main objectives of this project are:



\- To maintain book records.

\- To manage library members.

\- To issue books to members.

\- To manage returned books.

\- To calculate overdue fines.

\- To maintain borrowing history.

\- To generate library reports.

\- To provide an organized way to manage library information.



\## 4. Technologies Used



| Technology | Purpose |

|---|---|

| Python | Application development |

| Tkinter | Desktop graphical interface |

| SQLite | Database storage |

| hashlib | Password hashing |

| unittest | Automated testing |



\## 5. Main Modules



\### 5.1 Database Module



The database module manages the SQLite database connection and creates the required database tables.



\### 5.2 Authentication Module



The authentication module manages user login and password verification.



\### 5.3 Book Management Module



This module handles adding, viewing, searching, updating, and deleting book records.



\### 5.4 Member Management Module



This module manages library member information.



\### 5.5 Loan Management Module



This module handles issuing books, returning books, and calculating overdue fines.



\### 5.6 Reports Module



This module provides library information such as available books, issued books, overdue books, and member borrowing history.



\### 5.7 GUI Module



The GUI module provides the desktop interface using Tkinter.



\## 6. Database



The application uses SQLite. Its main tables are:



\- books

\- members

\- loans

\- users



\## 7. Loan and Fine Rules



\- Standard loan period: 14 days.

\- Fine rate: ₹5 per overdue day.



\## 8. Expected Benefits



\- Reduces manual record keeping.

\- Organizes book and member information.

\- Makes book issue and return management easier.

\- Helps track overdue books and fines.

\- Provides quick access to library records.



\## 9. Project Status



The project is under development. The availability of individual features in the graphical interface depends on their integration into the Tkinter application.



\## 10. Conclusion



The Library Management System demonstrates how Python, Tkinter, and SQLite can be used together to develop a desktop application for managing library activities.
